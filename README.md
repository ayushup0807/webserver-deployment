# Web Server Deplayment on Entreprise Linux

Deployed and configured Apache HTTP Server on RHEL-based enterprise Linux environment.

## Features
 - Virtual hosts for multiple domains (site1.local, site2.local)
 - Firewalld rules for HTTP/HTTPS
 - Self-signed SSL certificates for secure access
 - Automated setup via Bash script

## Usage
'''bash
sudo ./setup_webserver.sh
'''
